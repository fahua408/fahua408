## 🛡️ 1. [十字军之王3纹章生成工坊 (CK3 CoA Studio)](https://github.com/fahua408/CK3-CoA-Studio)
- **项目主页**：https://github.com/fahua408/CK3-CoA-Studio ｜ **在线文档页**：https://fahua408.github.io/CK3-CoA-Studio/
- **安装包下载**：[GitHub Releases 下载页](https://github.com/fahua408/CK3-CoA-Studio/releases)
- **功能简介**：专为《十字军之王3 / 王国风云3》(Crusader Kings III) 打造的图片转纹章可视化工具与**多纹章拼接合成器**（`coaConverter_windows.exe` 图形化工作台）。
  - 支持 **强制 1:1 正方形屏幕截图 (`Ctrl+Shift+A`)** 与 **1:1 正方形图片编辑器**（裁切 / 边缘取色留白填充 / 旋转 / 锐化增强），彻底解决图片进游戏被拉扁的问题；
  - 内置 **🧩 多纹章拼接工坊**：一键将多个纹章拼接为 **西班牙王室六合一（四分+格拉纳达底角+中央波旁小盾）**、**汉诺威三分+中央小盾**、**萨伏依/帝国九区大复合**、**经典四分+中央小盾**、**左右联姻二分**，并支持纯 TXT 纹章代码坐标直拼；
  - 自动关联管理 **原图 ↔ 纹章 `.txt` 代码**，7 万行大体积纹章代码 0.1 秒一键复制到剪贴板，进游戏点右下角「从剪贴板粘贴」即可复现任何图片（如卡皮巴拉、家族徽章、动漫头像）。
- **核心关键词**：`十字军之王3纹章` `十字军之王3图片转纹章` `CK3自定义纹章代码` `CK3纹章拼接` `CK3四分纹章` `coaConverter_windows.exe教程` `CK3 Coat of Arms Converter GUI` `Crusader Kings 3 Heraldry Merger`
